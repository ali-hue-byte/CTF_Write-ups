# Network services
## Description
Challenges covering vulnerabilities and misconfigurations related to network services.
## Challenges
#### Very easy
- [Meow](./../Boxes/Meow.md) — telnet, misconfigured root access
- [Fawn](./../Boxes/Fawn.md) — FTP, anonymous login
- [Dancing](./../Boxes/Dancing.md) — SMB, null/guest access without credentials
- [Crocodile](./../Boxes/Crocodile.md) — FTP, anonymous login, directory enumeration
- [Responder](./../Boxes/Responder.md) — File inclusion, UNC paths, SMB authentication capture
- [Vaccine](./../Boxes/Vaccine.md) — FTP anonymous login, password cracking, SQL injection, sudo misconfiguration
- [Archetype](./../Boxes/Archetype.md) — SMB anonymous login, privileges misconfiguration, plaintext credentials, reverse shell

- [Cap](./../Boxes/Cap.md) — FTP, SSH, password reuse, unauthenticated web access, CAP_SETUID
- [Nexus](./../Boxes/Nexus.md) — CVE-2026-38526, SSH, Git, Git object manipulation, SSH key generation, privilege escalation
- [TwoMillion](./../Boxes/TwoMillion.md) — CVE-2023-0386, SSH, Linux, command injection, reverse shell, privilege escalation
- [Support](./../Boxes/Support.md) — SMB anonymous login, hardcoded credentials, RBCD, privilege escalation, windows
