# CTF_Write-ups
A collection of my solutions and write-ups for various cybersecurity challenges, documenting my methodology in reconnaissance, exploitation, and vulnerability analysis.

## Objective
Documenting my progress in ethical hacking and penetration testing, detailing my reconnaissance, exploitation, and analysis methodology for each completed challenge, as part of my journey toward a career in cybersecurity.

## Typical Methodology
Each write-up generally follows this structure:

 - **Vulnerability**: description of the identified weakness
 - **Technique**: tools and approach used
 - **Steps**: detailed walkthrough with commands/screenshots
 - **Password/Flag found**: confirmation only, never disclosed

## Note
Passwords and flags are intentionally not disclosed in these write-ups, in accordance with good practice and the confidentiality rules of the respective platforms. Only completed ("retired") machines/rooms are documented.
